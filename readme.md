## how to run locally
1. download the files
2. go to the directory and double-click index.html
3. done its really that simple
### if you want a leaderboard
4. go to the files
5. go to /leaderboard
6. create a file called firebase-config.js
7. copy the file firebase-config.example.js
8. replace the values with your firebase config <3
